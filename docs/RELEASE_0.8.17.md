# Ninjacat Skies 0.8.17 — Back on track

Pack CurseForge client file **TBD**, server additional **TBD**.

Ninjacat Skies Core 0.5.17, Tribal Power 5.3.10 and Chocobos Reborn 1.0.19. Existing saves load as they are; no
quest ids change, and the mod list is unchanged at 104.

- **Chocobos Reborn 1.0.19 - Back on track** (project 1699008, file **8996621**): a wide line keeps the lap. Cut
  further than that, stay off the road for four seconds, or go over the edge, and you are set back where you
  left the road and held for a second. Every shortcut is marked where the road forks, and the HUD says whether
  this bird can take it. Birds from older versions convert once: old promotion marks become points of nine, and
  a bird with no born stats rolls a bloodline from its grade. Server and every rider need 1.0.19.
