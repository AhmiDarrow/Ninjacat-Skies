# 0.10.20 — Beans and Dirt

Tribal Power 5.6.4 and Ninjacat Skies Core 0.5.24: two fixes for things the first Clowder on a server runs into. Nothing new to build, nothing moved. Existing saves load as they are. 106 mods.

**Fixes**

- **The Beddown's totem takes plain Dirt.** The Frayed Totem for the first gate guardian asked for four Rooted Dirt, which a sky-start Clowder cannot dig up until very late. It is four Dirt around the Void Yarn now, like the other totems take their common block.
- **Glimmer Beans grow wild at last.** The Glimmer Ridge is moonstone and moss agate at the surface and the bean would only root in soil, so no wild patch ever landed. The bean now roots in ridge stone, and wild patches also grow across the far more common Crystal Fields. New chunks carry them; ground you have already explored stays as it is.
