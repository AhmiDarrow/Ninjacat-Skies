# 0.10.12 — Whistle Calls and Flute Songs

Chocobos Reborn 1.1.11 and Shamanic Mounts 0.1.12. Everything else stays as it is in 0.10.11.
Existing saves load as they are; no quest ids change. 106 mods.

**Chocobos Reborn**

- **The whistle has a voice.** The Chocobo Whistle sounds every time you blow it, with four different calls played
  in turn, so two blows in a row never sound the same. If no bird hears it, it rests for a second before the next
  blow.

**Shamanic Mounts**

- **Flute songs.** The Mount Flute plays a short wooden-flute phrase every time you blow it, four phrases in turn,
  instead of one note-block note only when a mount answered. If nothing answers, it rests for one phrase.
