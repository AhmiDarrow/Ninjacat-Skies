# Ninjacat Skies 0.6.1-alpha — Quests and Clowder controls

- Right-click the Whisker Codex to open the live FTB quest tree and rewards. Sneak-use still gives the next-step hint. The optional lore book is separately named Whisker Field Notes.
- The Island Charter now opens the Clowder team panel anywhere. Its Create New Team button opens the template picker. Sneak-use on solid Overworld pad ground seals spawn.
- A curated preset assigns 50 distinct shortcuts, including Grave/backtick for quests, K for Clowders, Alt+K for FTB parties, B for backpacks and J for the AE2 wireless terminal. World actions are scoped away from inventory-only shortcuts.
- The first launch applies missing/default bindings while preserving customized bindings. Options → Controls → Key Binds now has a Pack defaults button. Full controls notes are included in CONTROLS.md.
- Corrected the outdated C-key and Charter instructions in starter guides and help.

Save compatibility: no item/block IDs, quest IDs, world generation, island/team data or shared-life data changed. Existing respawn points remain intact. No world reset is required.

Validation: all companion mods build; five Ninjacat Skies server GameTests pass. A full-pack client connected to the verification server and opened quests through the Codex and hotkey, Clowders through the Charter and K, and the Create New Team template picker. All 50 bindings were verified against the client's saved options. Pack structure, quest consistency, item IDs, life rewards and export checks pass.

Minecraft 1.21.1 / NeoForge 21.1.249 / Java 21. Import the attached ZIP in CurseForge, or restart an already patched profile.
