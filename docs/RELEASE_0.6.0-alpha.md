# Ninjacat Skies 0.6.0-alpha — The living camp

Tribal Power 2.3.0 adds a standalone illustrated Spirit Codex with animated examples, search, bookmarks, creature portraits, live recipes and an explicit spoiler warning.

Ten connected quests introduce chunk anchors, hostile-spawn wards, automated crop tending, functional decorations, and ritual mob binding. Binding Effigies permit 512 successful summons before the three-voice ritual must be repeated; failed attempts consume nothing. Redstone controls every new device, and standard item handlers connect them to automation.

The pack contains 1,495 quests in 38 chapters. Existing rare shared-life rewards remain in place. The import ZIP includes the 400-by-400 profile logo and the polished spoiler-free Field Guide.

Validation: Tribal Power production build and 38 server GameTests passed; standalone book and live recipe screenshots inspected; pack structure, quest consistency, item IDs, life rewards and export checks passed. Full campaign playtesting continues.

Import the attached ZIP directly with CurseForge's Import option. Minecraft 1.21.1, NeoForge 21.1.249, Java 21; allocate 8 GB RAM.
