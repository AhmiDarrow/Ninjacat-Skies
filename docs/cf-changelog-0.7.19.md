# 0.7.19

- **Tribal Power 3.5.0 - The March reborn** (CurseForge project **1684851**, file **8918180**). New terrain, bigger caves and canyons, the vanilla ores set in March slate, Raw Game and March Leather, every March block repainted, and far lighter flora. Gate Drum return always brings you home.
- **Chocobos Reborn 1.0.4 - Wild Gysahl** (CurseForge project **1699008**, file **8918139**). Wild Gysahl now grows in the Reed Fen, Steppe and Highlands.
- Tribal Power now handles March chocobos itself (spawns in all six biomes, Flame in the Ember Wastes). The pack's duplicate spawns and gysahl patches are removed.
- **Whiskerwind Guide** in Clowder Hall: right-click to travel to Whiskerwind, on foot or mounted.
- **Existing worlds:** the old March is backed up inside the save and regenerated once. Set `retrogenMarch = false` in `tribalpower-common.toml` before loading to keep it.

1.21.1 / NeoForge 21.1.249. Existing quest ids are unchanged.
