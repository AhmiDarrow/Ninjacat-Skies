# Ninjacat Skies 0.8.13 — The Songkeeper's Drum

Pack CurseForge client file **8978123**, server additional **8978127**.

Ninjacat Skies Core 0.5.15, Tribal Power 5.3.6 and Chocobos Reborn 1.0.15. Existing saves load as they
are; no quest ids change, and the mod list is unchanged at 104. Shamanic Mounts waits for CurseForge's
approval and joins in a later pack.

- **Ninjacat Skies Core 0.5.14 and 0.5.15** (project 1689718, file **8978059**): Craftweave, a better
  crafting table at the vanilla table and the Tribal Bench (cycle between recipes that share a grid and keep
  your pick, craft a typed number of items that refill from your pack, bookmarks on a hover tab, clear the
  grid). The twelve Ninjacat guardian themes ship in Core and play on the Songkeeper Drum.
- **Tribal Power 5.3.3 to 5.3.6** (project 1684851, file **8978069**): the Songkeeper Drum becomes a rhythm
  game on 46 songs with four difficulties and duels; the Gate Rite uses the new drum game; Jade shows real
  Pulse in machines; decor hangs on fences, walls and chains; a new Wind Charm and the Hanging Rack; cells and
  goggles come back off gear; the Tribal Bench has the recipe book; a tidier Reagent Pouch; satchels stay out
  of their own vault; new sapling art; March biomes carry the common biome tags; **Spirit Charms cost much
  more, and the Sky Charm takes a Nether Star.**
- **Chocobos Reborn 1.0.15 - Long bloodlines** (project 1699008, file **8977931**): an emptied dash bar has to
  climb back to 50, intelligence slows stamina drain and strengthens boost pads, and bloodlines climb over many
  clutches with rare legendary sparks. Install on the server and every rider.
