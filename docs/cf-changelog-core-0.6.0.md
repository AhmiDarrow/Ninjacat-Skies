# Ninjacat Skies Core 0.6.0

**Ten languages.** The companion mods now follow the language you picked in Minecraft. Existing saves load as they are; no ids change.

Now available in Spanish, French, German, Portuguese (Brazil), Italian, Russian, Polish, Japanese, Korean and Chinese (Simplified). Follows your Minecraft language setting.

- Chat, items, the Whisker Codex, the title and pause screens, and the field guide use those languages. A line with no translation stays in English.
- Latin American Spanish uses the same text as Spanish.
- Brand names stay in English, including Ninjacat Skies.
- Switch language in game with **Options → Language**.
