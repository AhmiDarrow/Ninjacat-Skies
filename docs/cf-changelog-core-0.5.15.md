# Ninjacat Skies Core 0.5.15

**The guardian themes join the Songkeeper Drum.** Existing saves load as they are; no ids change.

- **Twelve Ninjacat guardian themes now ship with Core**: Beddown, Cogwright, Drumheart, Edgewalker, Grindmaw, Hivemind, Lint Golem, Overweaver, Sealbreaker, Tangle, Thornmother and Unwoven. With Tribal Power 5.3.6 or later installed, each one is a whole song on the Songkeeper Drum at four difficulties, charted from the recording itself.
- Tribal Power no longer carries this music inside its own jar, so it is half the download it was. The themes come with Core instead, where the guardians live.
- A tidy-up inside Craftweave: its operator self-test sits with the other test tools. Nothing players see changes.
