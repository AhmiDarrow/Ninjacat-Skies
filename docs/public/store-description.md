# Ninjacat Skies

**CurseForge Summary (one line):** Void skyblock quest pack — Loom Braid Strands, Tribal Power, Clowder islands. NeoForge 1.21.1 · 8 GB RAM.

The Loom of Worlds was cut. Only frayed pads of earth remain in the void. Take to the sky as a Skybound initiate, form a Clowder, and reweave reality one Strand at a time.

Follow the **Whisker Codex** through nine Strands — Soil, Stone, Sprout, Claw, Spark, Clock, Swarm, Sigil, and Spindle — while **Tribal Power** shamanic technomancy (Spirit Pulse, Song Bench Echo, Gate Drum → The March) braids into Hum / Bind / Reweave.

## Requirements

| | |
|---|---|
| **Minecraft** | 1.21.1 |
| **Loader** | NeoForge **21.1.249** |
| **RAM** | **6 GB minimum · 8 GB recommended** |
| **Playtime** | ~40–60 hours (Normal first clear) |

## After Install

1. Open the **Ninjacat Skies** profile → Profile Options.
2. Set Memory to **Recommended by Author** (8 GB) or Custom **8192 MB**.
3. Enable the **ninjacat-skies-ui** resource pack if the title screen looks vanilla.
4. In-world: read **How to Start**. On **Clowder Dock**, right-click the **Island Charter** → Create Team → pick a pad.

## Features

- Void islands with Clowder Dock spawn and Easy / Normal / Hard pads
- Clowder Hall hub dimension (`/clowder hub`)
- FTB Quests Loom Braid progression — 1,300+ authored quests across 34 chapters
- **Tension Post**: seat Strand tokens on your pad; each tribe chimes, the notches light, and the pad itself changes (hearth, footing, haste, luck)
- **The Fray**: the cut in the sky, visible over the Dock, thinning as the server reweaves
- **Whisker Codex** in-game book (Modonomicon): the Cut, the Loom Braid, and Nine Tribes entries that unlock as you play
- **Skyblock-tuned**: every mod is reachable from a bare pad — bees, Mystical Agriculture essences, Ars archwood and more all bootstrap from the sieve, no worldgen required
- **Bees on a void pad**: craft a nest from a ring of logs or grit around a flower and wait for wings; every Productive Bees line starts there
- Voidloom stations: a Loomframe that sifts on its own, a Tension Barrel that batches — the pad's first machines
- FancyMenu branded title (void sky, paw logo, indigo/teal buttons)
- Tribal Power 2.0.1 as a core pack pillar (also playable standalone)
- Create, Mystical Agriculture, Productive Bees, AE2, Mekanism, Occultism, and more — woven into original quests

## Multiplayer

Form a Clowder, claim an island together, and progress as a team. Skyblock Builder + FTB Teams power shared pads and quest credit.
