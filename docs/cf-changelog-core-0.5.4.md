# Ninjacat Skies Core 0.5.4

One new thing: a shared Clowder life you can earn more than once. Existing saves load as they are; no ids change and nothing already earned is touched.

**A repeatable life**

Six quest milestones hand out a **Thread of Return**, one each, and then that is the end of them — which is thin for a pack this long. The Thread of Return is now also an item.

- **Thread of Return** — right-click it for exactly **one** shared Clowder life. It keeps no receipt, so a Clowder can earn it again for as long as it can pay. Crafted from four **Thread Shards** around a Braid Cord.
- **Thread Shard** — the lives piece. The mod ships the item and the Thread of Return recipe; a pack decides what a Shard costs.
- The six milestone rewards are unchanged and still one per Clowder each. Nothing grants more than one life at a time, and there are still no mob-drop, loot-crate or free repeatable life rewards.
- A Clowder at zero is already spectating and cannot use an item, so a Thread of Return has to be **held before the pool empties**. It is insurance, not a resurrection. With `hardcore.livesEnabled = false` it refuses to be spent rather than being wasted.

Both items are drawn to the 32x32 house style: a heart woven whole again with a copper knot in the cleft and bone stitching down the four seams, and a quarter snapped out of it with the fibres still hanging from the break.
