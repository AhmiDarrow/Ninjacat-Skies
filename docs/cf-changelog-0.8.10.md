# 0.8.10 — Your keys, your gear

Tribal Power 5.1.0. Existing saves load as they are, no quest ids change, and the mod list is
unchanged at 104.

- **Tribal Power has its own heading in Options › Controls.** The four Gate Rite drums (A, S, D, F
  by default; the arrow keys still work), the ley goggles, the Sixfold Staff's next voice, the
  satchel's personal / camp vault, the Pulse HUD, and a new **Gear screen** on the apostrophe key.
  Most ship unbound so they never collide with the pack's shortcuts; bind what you want.
- **Every worn Spiritweave piece has an off switch** in the Gear screen. Off, it still protects like
  armor but gives no effect and draws no Pulse: no night sight from a hood you want dark, no speed
  on a narrow ledge, no slow fall when you mean to drop. The tooltip says so in red.
- **The satchel names its vault.** If you are in a camp, the Wayfarer Satchel and Deep Cache open
  the camp's shared vault; sneak-use, the vault key or the Gear screen switch to your personal one,
  and the switch is announced. If a satchel seems to show a Clowder mate's things, that is the camp
  vault: switch to personal for your own.

**Server owners:** nothing changes for you. Unzip the new server pack over the old folder and run
`install` again.

Minecraft 1.21.1 / NeoForge 21.1.249 / Java 21.
