# Ninjacat Skies 0.7.3-alpha — Tribal Power 3.2

Tribal Power **3.2.1** (The Listening Pit and the Gates) comes into the pack with every one of its additions wired into the quests, the Codex, the tooltips and the controls. Companion mods are **Core 0.4.2**.

Tribal Power 3.2.1 (project 1684851, file **8858043**) and Ninjacat Skies Core 0.4.2 (project 1689718, file **8857851**) are the CurseForge pins.

## Tribal Power 3.2 — the Listening Pit and the Gates
Same content as Tribal Power 3.1.0, shipped under 3.2.x so CurseForge can process a new file. 3.2.1 is packaging-only (no leftover QA in the published jar). Tribal Weave (chapter 34) grows by 25 quests, all reachable from a void pad because the new crafts sit behind the Gate Drum, Echo stages and March reagents already on the chapter:

- **Placement is the ritual.** Stone Font, *Draw the Circle*, *Stone Stays*, Codex pattern ghosts, and the Drumheart's retuned tempo.
- **The Listening Pit.** Resonance Mesh, Anchor Stones, *Ask the Ground*, metals versus gems, and what each voice trades at the pit.
- **The Gates.** Gate Frame, Gate Keystone, *Open the Way*, Gate Sigil, *The Long Thread*. The Gate Drum is still the portable way into the March.
- **One voice, one source.** Ember Horn, Wind Harp, Wave Drum, Wake Bell, Loom Anchor, Pulse Cairn, and *Six Voices Singing*.
- **Also.** Spring Calling, the Drum Circle music disc (optional — chest at the circle, or The Unsung), and the Rite Circle / automatic pedestal loop.
- Existing quest progress is kept: no quest changes id. Tablet-rite text now asks for a Rite Circle; brazier blessings are unchanged.

The Whisker Codex gains *The Listening Pit and the Gates*, Living Lattice pages for patterns, fonts, generators and gates, tribe camps name the working device each tribe shows, and The Unsung mentions the disc. Tooltips on the new items point at Tribal Weave. Those Codex pages ship in Core 0.4.2.

The Codex is one book. Right-click always opens it (The Work, The Cut, The Loom Braid, Nine Tribes, Snapped Guardians). Grave (`) is the live assignment list and rewards — the same campaign, not a Shift-click mode. *The Work* names the braid in order: Knot, then seat the token at the Tension Post. Pack overlay + KubeJS apply that on Core 0.4.2; the Java one-mode item is ready for the next Core.

Save compatibility: content only. New quests, new Codex pages, new tooltips; nothing existing changes id. Tribal Power 3.2.1 is itself save-stable per its release notes; its structures appear in newly generated March chunks. Minecraft 1.21.1 / NeoForge 21.1.249 / Java 21.
