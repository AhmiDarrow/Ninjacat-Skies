# Ninjacat Skies 0.10.0 — Loom's End

Pack CurseForge client file **pending**, server additional **pending**. Core 0.5.18 is CurseForge file **9002736**.

105 mods (101 on the server): Ninjacat Skies Core 0.5.18, Tribal Power 5.3.10, Chocobos Reborn 1.1.0, Shamanic Mounts
0.1.3. Existing saves load as they are; no quest ids change. The first visit to Clowder Hall after updating rebuilds
the hub once as Loom's End; the drop chest and any Yarn Basket are left exactly as they were.

See `docs/cf-changelog-0.10.0.md` for the player-facing notes. In the repo:

- The hub town is pack data: `pack/overrides/kubejs/data/clowderhall/towns/clowder_town.json`, generated by
  `tools/generate_hub_towns.py clowder` from `tools/hub_loomsend.py` (revision 2). Never hand-edit the plan; the
  HubTown gate (`tools/gates/test_hub_town.py`) regenerates and compares, checks the ceremony cells, keeper posts,
  beds per townsperson, Sunfeather and the saddle listing. The generator also writes the keeper table in
  `dock_stalls.js`.
- Ten keeper stalls; stock redistributed and 55 goods added (`dock_shop/<stall>_*.json`); quest and codex text points
  at the new keepers.
- `hub_life.js` protects the residents; `hub_protection.js` locks the Hall down to the drop chest, yarn baskets,
  doors, drums, bell and craft-only tables.
- Server installer fixes from the bug sweep: `install.bat` from a PowerShell 7 prompt, `install.sh` reading a record
  written on Windows, bracketed folder names refused, PowerShell 5.1 download speed and TLS; covered by
  `ServerInstallerTests` in the GateRegressions gate.
- Performance: the whole town force-loaded costs 4.4 ms/tick (233 entities); an empty Hall costs 0.005 ms and nothing
  keeps it loaded.
