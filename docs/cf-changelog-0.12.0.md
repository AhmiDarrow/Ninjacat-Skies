# 0.12.0 — Ten Languages

The quest book and the companion mods now follow the language you picked in Minecraft. 106 mods. Existing saves load as they are.

Now available in Spanish, French, German, Portuguese (Brazil), Italian, Russian, Polish, Japanese, Korean and Chinese (Simplified). Follows your Minecraft language setting.

- **Quest book.** Chapters, tasks and rewards are translated. A line with no translation stays in English.
- **Ninjacat Skies Core 0.6.0.** Chat, items, the Whisker Codex, menus and the field guide use the same languages. Brand names stay in English, including Ninjacat Skies.
- Latin American Spanish uses the same text as Spanish.
- Switch language in game with **Options → Language**.
