# Ninjacat Skies 0.8.2 — Plain sight

Pack CurseForge client file **8925530**, server additional **8925533**.

New builds of the pack's own three mods, a bug sweep across them and the pack, one art pass over everything, and the End Apple. Existing saves load as they are; no quest ids change.

- **Ninjacat Skies Core 0.5.3** (project 1689718, file **8925254**): the End Apple (five ender pearls, two bones, two blaze powder — one bite there, one bite back) and a new End-chapter quest; Driftwrecks, Voidloom and Guardians art redrawn at 32x32; pixel-quantised Guardian and Remnant textures; canonical tribe glyphs shared with Tribal Power; 17 fixes, including order cues that fired all at once, boss fights that did not survive a restart, and stage blocks that dropped nothing. Changelog: `docs/cf-changelog-core-0.5.3.md`.
- **Tribal Power 3.6.2 - Plain sight** (project 1684851, file **8925225**): creature drops, grits, exotic woods and machine tops redrawn; 16 fixes, including gate bounce, familiar health, Spiritgear swing ownership, per-tick Pulse cost and tank faces. Changelog: `../tribal-power/docs/RELEASE_3.6.2.md`.
- **Chocobos Reborn 1.0.7 - Fresh paint** (project 1699008, file **8925242**): every item, block and crop stage redrawn at 32x32 (the bird is untouched); course bogs, entered odds, scratching, crash-left fans and ledger saves fixed; Carob prize docs corrected. Changelog: `../chocobos-reborn/docs/RELEASE_1.0.7.md`.
- **Pack content**: unfinishable quests fixed (Spirit Fire, Pam's Apple, Square Gate), the retired Desk removed from five quests, the Nether chapter rewritten for a void Nether, quest and Codex text matched to the new mod versions, and the pack's sieve extras added to Voidloom meshes and March soil.
- **Setup**: the shipped `ninjacatskies-common.toml` now carries every key (no more `.bak` on first launch, gated by ShippedConfigs), and Silent Gear's "open item" moved to **Alt+O** off the backpack's Alt+X toggle, with a one-time migration for existing installs.

Pins: Ninjacat Skies Core 0.5.3 (project 1689718, file **8925254**), Tribal Power 3.6.2 (project 1684851, file **8925225**), Chocobos Reborn 1.0.7 (project 1699008, file **8925242**). Minecraft 1.21.1 / NeoForge 21.1.249 / Java 21.
