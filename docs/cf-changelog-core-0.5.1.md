# Ninjacat Skies Core 0.5.1

- **New companion mod: Driftwrecks.** After a Clowder tensions Soil, pieces of the old world drift up to its pad, hold for a while and unravel. Every wreck is assembled on arrival from parts (deck shapes, core variants, shared ruins, islets), so no two drift in alike. Tether Spool bridges, five objectives, six modifiers, per-player chests with Salvage Bundles, the Wreck Atlas, 54 Keepsakes, sealed rifts with nine Remnants, and the Heartwreck. Config: `driftwrecks-server.toml`.
- Ninjacat Lib gains a shared block-plan reader and a tick-spread build queue; the Snapped Guardians use them and share their mesh renderer with Driftwrecks.
- Whisker Codex: a Driftwrecks category.
