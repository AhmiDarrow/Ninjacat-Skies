# 0.8.1 — Safe keeping

A bug-fix update of the pack's own mods. Existing saves load as they are; no quest ids change.

- **Ninjacat Skies Core 0.5.2** (CurseForge project **1689718**, file **8923743**). Snapped Guardians: a guardian knocked off its stage is put back (the void no longer wins the relic), arena blocks drop nothing and shrug off explosions, death drops come home, the fallen aren't pulled back in on respawn, an empty arena ends after five minutes. Driftwrecks: objectives, chests, mobs and rifts only appear where you can walk; Hold crypts have working stairs and the watchtower a ladder; a failed arrival can't affect the server. Joining a party syncs Strands at once; `sunderedSky = false` restores the vanilla sky; the Island Charter seals a spawn that holds; the Tension Barrel and Loomframe no longer lose or jam items; no second starter kit.
- **Tribal Power 3.6.1 - Safe keeping** (CurseForge project **1684851**, file **8923709**). Other players can't break your Camp blocks, Stone Font, Gate Keystone or Resonance Mesh. The air charm no longer switches off flight from other mods. Seated Pulse cells come back when Spiritweave breaks. A safer March reset. Dock stall stock no longer refills on relog. The Unsung can always be finished. Performance work on Song Benches, Echo Stations, companions and the Ley Lens.
- **Chocobos Reborn 1.0.6 - Fair bets** (CurseForge project **1699008**, file **8923710**). No more stranding on a vehicle when going to or from Whiskerwind. Teleports work while riding a flier. Fair Field betting. Bets and duel stakes survive a crash. A traded bird's gear stays with the bird.
