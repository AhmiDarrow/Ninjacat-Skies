# 0.8.16 — Held pace

Chocobos Reborn 1.0.17. Core stays 0.5.17 and Tribal Power stays 5.3.10. Existing saves load as they are,
no quest ids change, and the mod list is unchanged at 104.

- **Other birds stay smooth.** A chocobo you are not riding follows the server every tick. A late update
  glides instead of popping back. Install this pack on the server and on every rider.
- **The field holds its own pace.** A gap to you does not speed the other racers up or slow them down.
- **Nine points promote.** A sprint win is 1. A grand prix win is 3. The class never drops. Marks already
  on a bird count as that many points, so two wins toward the old three are now two of nine.
- **Purses match that ladder.** A sprint pays 6 / 12 / 24 / 48 GP for C / B / A / S. A grand prix pays three
  times that. A chocobo saddle is 8 GP, Sylkis is 80, and Zeio is 96.
- **The birds blink,** the tail sits on the body, and the beak stays orange on every breed.

**Server owners:** unzip the new server pack over the old folder and run `install` again.
