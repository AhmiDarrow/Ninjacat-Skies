# Ninjacat Skies 0.7.17

Clowder Hall protection. Skyblock Builder's spawn protection only reaches the Dock in the overworld, so `kubejs/server_scripts/hub_protection.js` now guards `clowderhall:clowder_hall`: block break and place are cancelled, explosions are cancelled, and right-clicking a block with a bucket, flint and steel, fire charge, bone meal, axe, shovel or hoe is cancelled. Creative-mode players are exempt so the town can still be edited. Carries the 0.7.16 keeper de-duplication.
