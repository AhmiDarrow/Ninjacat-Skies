# 0.8.7 — A braid needs a Post

Ninjacat Skies Core 0.5.6. Existing saves load as they are, no quest ids change, and nothing a
Clowder has already seated or earned is touched.

- **The Braid Cord is reachable again.** Spinning one used to require two of **Clock**, **Swarm**
  or **Spark** seated at your Tension Post. A Strand token is what you get for finishing a whole
  Strand chapter, so that put the Cord — and the **Thread of Return** built around it — most of
  the way through the pack, behind exactly the players least likely to have a spare life to fall
  back on. Now it is a price rather than a gate: hold **16 Strand Filaments**, right-click the
  Post, take the Cord. No Strand has to be seated.
- **The price is work, not a wall.** Filaments come out of a sieve — gravel, sand or dust through
  an iron Thread Mesh — and a Tension Post is logs around a Binding Knot with a scrap of Thread on
  top. A Post that is short takes none of your filaments and tells you how many more it wants.
- **The books say so now.** The Codex, the starter book, both Bind quest descriptions and the
  Strand Filament's own tooltip were all still telling you to seat two Strands first. They have
  been rewritten.
- **The rest of the Post is unchanged.** Strand tokens still seat the same way, the **Spindle Loom
  Fragment** still wants all nine Strands and a March stone, and seating the Fragment is still the
  Reweave.

Worth saying plainly: a **Thread of Return** is four **Thread Shards** around the Cord, and a Shard
is unchanged — four diamonds, four Void Yarn and a Rift Shard from a mended Remnant, or **400
Frayed Thread** from the Spark stall at `/clowder hub`, four a day. Mending a Remnant needs a Weft
Key, and the Salvager only sells those once seven Strands are seated, so the crafted route is still
a late one. The stall route — 1600 Thread and a braid — is the one this release opens up.

**Server owners:** unchanged from 0.8.5. The server zip leaves out the four client-only mods
(Sodium, Reese's, BadOptimizations, Dynamic FPS); clients get all 104, servers 100. Unzip the new
server pack over the old folder and run `install` again.

Minecraft 1.21.1 / NeoForge 21.1.249 / Java 21.
