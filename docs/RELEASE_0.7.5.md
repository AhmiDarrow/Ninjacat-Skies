# Ninjacat Skies 0.7.5

Gameplay and gate fixes over 0.7.4. Ships **Ninjacat Skies Core 0.4.3** (the 0.4.2 CurseForge jar did not match the claimed Hub/arena/lives behaviour).

- Hub Key will not pull you out of an arena. Returning from the Hall never lands on a spent stage. Hall beds no longer overwrite pad spawn. The ceremony chest is stamped on first visit even if worldgen already filled it.
- An arena full disconnect no longer spends the totem after five seconds. Lint Golem requires Soil; Tangle requires Claw. Guardian temp blocks and mechanic ledgers persist across a save.
- Shared lives remember exhausted mates who are offline. The Overweaver relic restores one life, not the whole Clowder. Tension Posts and seated Strands follow a pad when FTB promotes the solo team into a party.
- Whisker Codex right-click always opens the campaign book (Grave `` ` `` is still the assignment list). Farmer's Delight sieve extras also drop on Voidloom thread meshes.
- QA gates understand Core jar-in-jar (item ids, pack structure, smoke, CurseForge 89/89, reachability `both()`/`sieve()`).
