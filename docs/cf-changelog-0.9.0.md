# 0.9.0 — The Spirit Herd and a Full Grid

Shamanic Mounts joins the pack, Chocobos Reborn 1.1.0, and 25 mods updated to their latest release. Core stays
0.5.17 and Tribal Power stays 5.3.10. Existing saves load as they are and no quest ids change. 105 mods.

- **New: Shamanic Mounts.** Breed spirit mounts with real genes: ten founder lines, pelts, sizes and gifts that
  pass to foals, saddle bags and horse armour, and a Herd Book to track your lines. They also roam the March.
- **Chocobos Reborn 1.1.0 - Full Grid.** Forty-eight courses. Sprints are one long lap, grands prix short
  circuits of three to five laps. Racers are solid and bump. Points and purses grow with the length of the race.
  Smarter AI and cleaner courses. Flame and Purple birds no longer race.
- **Updated:** FTB Library, FTB Quests, Balm, Entity Culling, ImmediatelyFast, Applied
  Energistics 2, KubeJS, Ars Nouveau, Productive Bees, Sophisticated Backpacks / Core / Storage, HammerLib,
  Iron's Lib, GeckoLib, GuideME, Modonomicon, Create: Enchantment Industry, Create Crafts & Additions,
  Create: Dragons Plus, FramedBlocks, Moonlight Lib, Supplementaries, Xaero's Minimap and Xaero's World Map.

**Server owners:** unzip the new server pack over the old folder and run `install` again. Install this pack
on the server and on every player.
