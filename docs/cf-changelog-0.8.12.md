# 0.8.12 — Steady dash

Chocobos Reborn 1.0.14. Existing saves load as they are, no quest ids change, and the mod list is
unchanged at 104.

- **A guest's dash spends stamina again.** After the first time the bar hit empty, it filled back
  up and stayed full while they kept sprinting. Holding sprint and riding forward spends stamina,
  for the host and for a friend on the same world.
- **The host pack is enough.** A guest who has not updated still gets that fix.
- **A short lag spike no longer yanks the bird back.** A chocobo may move up to 40 blocks in one
  tick. A real teleport across the course still snaps to where the server put them.
- **The Gear screen opens on numpad minus.** Grave stays the assignment list. A Gear key still on
  Tribal Power's apostrophe default moves to numpad minus. A key you already chose stays where you put it.

**Server owners:** unzip the new server pack over the old folder and run `install` again. The Gear
key is a client control.

Minecraft 1.21.1 / NeoForge 21.1.249 / Java 21.
