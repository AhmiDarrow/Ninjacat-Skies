# Ninjacat Skies 0.8.3 — Solid ground

A Chocobos Reborn build only: the race courses in Whiskerwind. Existing saves load as
they are; no quest ids change and no other mod moves.

- **Chocobos Reborn 1.0.8 - Solid ground** (project 1699008, file **8926685**): the
  course islands no longer have holes to fall through (761 across the twenty-four, 152
  bird-sized) and the fall rescue catches every drop; riders are invulnerable in
  Whiskerwind like the birds, with a void catch on foot; every terrain feature re-placed
  so a colour is worth about 2 % of a lap on all twenty-four courses, with the bog always
  the cheapest thing to go round; three boost strips per sprint and five per grand prix on
  corner exits; features spread round the lap and clear of the run off the grid; a
  landmark of its own on every course; scenery, rails and pools kept off the racing line
  and pools walled in. Changelog: `../chocobos-reborn/docs/RELEASE_1.0.8.md`.
