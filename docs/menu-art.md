# Main-menu art and layout

The menu uses `pack/overrides/config/fancymenu/assets/title_aurora.png`, generated with the built-in image generation tool. It is an illustrated title backdrop, not an in-game screenshot. The FancyMenu layout keeps actual native button actions, adds a larger title, makes the Field Guide central, and scales against a 1280x720 layout rather than the previous 1920x1080 layout that made small windows feel empty.
