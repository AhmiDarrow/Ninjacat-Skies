# Ninjacat Skies Core 0.5.22

**Every piece explains itself.** A polish pass with nothing new to build. Existing saves load as they are; no ids change.

- **Hints on the things that had none.** Hover the End Apple and its bitten half, the Drift Needle, Tether Spool, Driftwreck Seal, Salvaged Weft, Salvager's Frame, Salvage Crate, Frayed Spawner, Rift Shard, Wreck Atlas, Trophy Plinth, the nine Strand banners and the three Thread Meshes, and a grey line says what each is for. The items the pack already describes keep their pack text; nothing is said twice.
- **Tooltips wrap.** Long hint lines fold to tooltip width instead of running off the screen.
- **Mods list.** Every companion mod now links to the Core's CurseForge page and the issue tracker, and Ninjacat Skies carries the Core logo.
