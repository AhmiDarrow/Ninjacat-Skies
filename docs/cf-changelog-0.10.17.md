# 0.10.17 — Separate Destinations

Tribal Power 5.6.1. Everything else stays as it is in 0.10.16. Existing saves load as they are. 106 mods.

**Tribal Power**

- **Each relay channel can go somewhere else.** On a ranked item or fluid plate, mark a face and use the Lattice Tuner. Each plain click fills the next channel that has no destination.
- **Sneak-click retargets the selected channel.** The plate names that channel's coordinates and face.
- **One transfer a beat, as before.** An empty filter still sends to the first channel with room. Give later channels a filter, or switch to round-robin, when they should receive goods first.
