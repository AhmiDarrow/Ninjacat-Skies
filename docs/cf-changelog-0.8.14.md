# 0.8.14 — Every drum sounds

Ninjacat Skies Core 0.5.16 and Tribal Power 5.3.7. Existing saves load as they are, no quest ids change,
and the mod list is unchanged at 104.

- **The Ninjacat guardian themes play on the Songkeeper Drum.** In 0.8.13 the twelve guardian songs were
  listed but silent: their recordings carried a leftover cover picture the game could not read past. They
  are plain audio now, the same sound to the millisecond, so every chart still lands on the beat.
- **A, S, D and F always drum.** A rebound key could leave one pad dead. The drum now takes your own lane
  keys, plus A S D F and the arrow keys.

**Server owners:** unzip the new server pack over the old folder and run `install` again.
