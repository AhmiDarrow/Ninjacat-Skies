# 0.8.4 — Thread of Return

Ninjacat Skies Core 0.5.4 (file 8927258). A shared Clowder life you can earn more than
once, and a counter that buys Frayed Thread back off you. Existing saves load as they
are, no quest ids change, and nothing a Clowder has already earned is touched.

- **A life you can earn again.** Six quest milestones hand out a **Thread of Return**,
  one each, and after the sixth that was the end of them — thin for a pack this long.
  The Thread of Return is now also an item: right-click it for exactly one shared
  Clowder life, as often as you can pay for another. It keeps no receipt, so the price
  is the limit rather than a counter, and the six milestone rewards are unchanged and
  still one per Clowder each.
- **Four Thread Shards make one.** The Shard is the lives piece; four of them around a
  Braid Cord stitch into a Thread of Return. Cut a Shard from four diamonds, four Void
  Yarn and a **Rift Shard** — so the crafting path is gated behind mending a Remnant —
  or buy one from **Spark** in Clowder Hall for **400 Frayed Thread**, four a day. One
  life is four Remnant kills, or 1600 Thread. There are still no mob-drop, loot-crate or
  free repeatable life rewards, and nothing grants more than one life at a time.
- **Hold one before you need it.** A Clowder at zero is already spectating, and a
  spectator cannot right-click anything. A Thread of Return only helps if someone is
  carrying one when the pool runs out. That is on purpose: it is insurance, not a
  resurrection, and an operator revive is still the answer to a Clowder that ran out
  without one.
- **Grit buys materials back for Thread.** A new counter at `/clowder hub` takes blocks
  of copper, iron, gold, amethyst, emerald and diamond, and netherite ingots, and pays
  Frayed Thread for them — badly. A whole diamond block comes back as 24 Thread while
  Spark sells two diamonds for 80, so every rate is nine to fifteen times worse than
  buying the same material back and no loop pays. Stock returns each Minecraft day.
- **The Codex covers both.** *When progress stops* now explains the item path and the
  warning about holding one early, and *Frayed Thread* has a page on the exchange counter
  and what a life actually costs in blocks.
