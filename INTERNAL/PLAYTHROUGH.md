# 40–60 Hour Playthrough Scope

Ninjacat Skies is scoped as a **full extensive void-island campaign**, not a thin demo.

**Classic skyblock flow = inspiration only.** Do not treat void → sieve → farm → forge → power → magic → digital as the finished product. The campaign must evolve into Loom-native systems, parallel Clowder routes, and a reweave late game. See `INTERNAL/PLAN.md`.

## Design targets

| Metric | Target |
|--------|--------|
| First clear (Normal, first-time) | **40–60 hours** |
| Main quests | **1322** (34 chapters) |
| Side / repeatable / shop sinks | **150–250** |
| Strands fully authored | **All nine** |
| Resource paths | Sieve/Voidloom + crops + bees + Create sifting (mix allowed) |
| End trophy | Spindle Loom Fragment (creative-tier adjacent, gated) |

## Loom Braid pacing

Progression is the **Loom Braid**, not a single ladder:

`Wake → Recover → Root → Edge → (Pattern ‖ Colony ‖ Hum) → Bind → Reweave`

| Band | Hours | Phases | Intent |
|------|-------|--------|--------|
| Early | 0–10h | Wake / Recover | Void survival; **Voidloom Recover** identity (sieving is a tool, not the chapter title) |
| Settle | 10–26h | Root / Edge | Living pad + kit/footholds; open the braid |
| Mid | 26–42h | Pattern / Colony / **Hum** | Three **peer** paths; any two can carry a Clowder into Bind |
| Late | 42–60h | **Bind** / **Reweave** | Steward contracts → digital loom + trophy |

**Tribal Power** is core muscle for **Hum / Bind / Reweave** (Spirit Pulse as primary Hum fantasy; rites/seals as Bind tools; March foothold on full Spindle clear). Do not softlock Wake–Root on Tribal. Pattern (Create) and Colony (bees) remain peer braid paths—Tribal assists, does not replace them.

Tension from Wake+Recover+Root+Edge plus any two braid clears plus Bind feeds Spindle gating (tunable).

## Pacing principles

1. **Early game (0–10h)** teaches void survival without softlock; sieving stays engaging via Voidloom yarn sinks.
2. **Mid game (10–40h)** opens parallel braid routes (farm / bees / Create / pulse-tech) so multiplayer Clowders can specialize.
3. **Late game (40–60h)** collapses into Bind infrastructure + AE2 autocraft + March/Reweave trophy work; still requires built bases, not creative pop.

## Gating (KubeJS + quests)

- Soft gates: quest rewards unlock key seeds, meshes, schematics
- Hard gates: a few recipe replacements (e.g. first controller, first reactor casing) that force Strand progress
- Braid gate: Bind after any two of Pattern/Colony/Hum (Braid Cord or equivalent quest logic)
- Never gate *fun building*—gate *power spikes*
- Never gate Soil–Root on Tribal

## Difficulty presets

- **Easy (Dojo Cottage):** more kit, gentler sieve tables, three lives per member in the shared team pool
- **Normal (Ninjacat Pad):** design center for 40–60h
- **Hard (Frayed Thread):** sparse kit, leaner drops, three lives per member in the shared team pool

## Multiplayer

Same campaign length. Shared Strand cosmetics at hub. Per-Clowder islands. Shop currency personal or team-configurable. Pulse networks and March visits stay Clowder-friendly when Tribal is woven.
