# Ninjacat Skies — Inspection & Polish Review (2026-09-06)

Scope: everything in the repo — `docs/`, `INTERNAL/`, the four custom mods, KubeJS scripts, FTB Quests (34 chapters / 1324 quests), Skyblock Builder config, FancyMenu notes. Tribal Power lives in its own repo and is judged here only through how the pack uses it.

---

## The short read

The *writing* layer is strong and specific. The story bible, tribe roles, Loom Braid shape, the rule "no chosen one, no prophecy dumps", the vocabulary (sift, tension, splice, knot, reweave) — all of it is distinctive and consistent. The *shipped experience* does not yet carry that voice. Almost all of what a player touches is generated: 1324 quests that are every one of them "obtain item X", 64% of descriptions are two words, 97% of rewards are one Frayed Thread, and the custom items that are supposed to be the campaign's spine (Strand Tokens, Braid Cord, Codex Pages, the Spindle Loom Fragment) are either trivially craftable or completely inert. The pack currently *tells* the story in docs and *plays* like a checklist.

The good news is that the fixes are concentrated. Roughly five changes (token ceremony, Tension scope, the Codex as a real book, three Voidloom mesh drop tables, a quest regeneration pass with real task types) would flip most of the experience from "assembled" to "authored". Below: the issues first, then the original effects to add, then a suggested order.

---

## Part 1 — Issues

### P0: structural (break the design promise or the save)

**1. Strand Tokens are Soil-tier crafts, so every gate built on them is a no-op.**
`strand_gates.js` makes every token from 2 Frayed Thread plus two mundane items: Soil = dirt + sapling, Swarm = honeycomb + glass bottle, Sigil = amethyst + book, Spark = redstone + coal. A player on hour two can craft Soil, Stone, Sprout, Claw, Spark tokens; Swarm and Sigil come from the Desk shop (honeycomb and amethyst are sold for Thread). That means Braid Cord (the Bind gate), the AE2 controller / molecular assembler / precision mechanism soft-gates, and eight-ninths of the Spindle Loom Fragment are bypassable before the first sieve. The only real gate in the entire late game is `tribalpower:march_stone`. The plan's own anti-pattern list — "Strand soft/hard gates: distinct token crafts + a few meaningful recipe gates (not no-ops)" — is currently violated by the shipped recipes. Fix in Part 2 (Token Ceremony).

**2. Loom Tension is exploitable and per-player, not per-Clowder.**
`loom_tension.js` grants `STRAND_POINTS` on *every* token craft with no once-per-strand flag (Braid and Fragment have flags; Strands don't). Crafting fourteen Soil tokens unlocks all three milestones, including a free Braid Cord. Separately, Tension and Steward flags live in `player.persistentData`, while quest rewards are team-scoped (`default_reward_team: true`). In a Clowder, the mate who didn't craft the token never hears the whisper and never gains Tension. The story says Clowders reweave together; the data says individuals do.

**3. Several main-path quest items cannot be obtained in this world.**
Void overworld, custom Nether, custom End (`keepMainIsland` only). Non-optional quests asking for these will dead-end a chapter:

| Chapter | Item | Why it's a problem |
|---|---|---|
| 15_clowder (main) | `recovery_compass` | Echo shards are Ancient City loot only |
| 23_end, 33_mobfarm (main) | `heart_of_the_sea` | Buried-treasure / fishing-treasure only; no oceans |
| 21_decor, 33_mobfarm (main) | `prismarine`, `prismarine_shard/crystals` | Guardians need an Ocean Monument |
| 23_end (main) | `elytra` | End Cities — verify outer End generates; likely not |
| 08_sigil, 23_end, 33_mobfarm (main) | `totem_of_undying` | Evokers only; needs raids with villagers on a pad. Feasible but brutal without a note |
| 33_mobfarm (main) | `rabbit_hide` | No rabbits without spawn eggs |
| 22_nether (main) | `ancient_debris`, netherite | Verify Ex Deorum sieve/crushed-netherrack path exists in 3.12; if not, dead end |
| 23_end (main) | purpur / chorus / end rod / shulker | Requires outer End islands — confirm `dimensions.json5` End settings actually generate chorus |

Either add pack recipes (a Thread Desk sale, a Voidloom mesh drop, a Mystical Agriculture seed), or move them to optional with an honest description. `tools/audit_quest_items.py` only checks IDs exist, not that they're reachable — worth adding an "unreachable in void" denylist to it.

**4. Nothing is committed.**
`git log` reports the branch has no commits; all 1725 files are untracked. One bad `rm -rf` or a failed sync and a full day's work is gone. Make the initial commit today (dist/ is already ignored).

**5. Design-doc voice leaks into player-facing text.**
This is the biggest cohesion problem because it's the one players will actually notice. Examples currently shipping:

- Steward lines (`steward_lines.js`): "Rhythm first—Tribal Power as primary hum. Bridge FE later if you must." / "Gear is a braid strand—peer to Swarm and Spark, not a ladder rung." / "Bees and deep crops braid beside Clock. Specialize; do not choke." These are PLAN.md sentences with the tribe name pasted in front.
- Whisker Codex right-click prints "Loom Braid: Wake → Recover → Root → Edge; then Pattern, Colony, Hum as peers; Bind; Reweave." — the progression diagram as chat.
- Quest descriptions: "Sieve is a tool, not the title.", "FE bridge buffer — not the Hum religion.", "Powah/Mek are FE bridges.", "If found — optional.", "If you somehow find water seas.", "If present — late.", "Summon focus — Bind braid is already on the main path." The word "bait" appears in twelve descriptions ("Sigil bait", "Swarm bait", "Boss bait trio").
- Steward whisper color `0x2A2F4F` (void indigo) is near-invisible on the default chat background.

The style guide already forbids this ("never walls of text", "no prophecy dumps") — it just needs a pass that asks of every line: *would a Pad-keeper say this?*

### P1: the quest layer is bulk, not authorship

- 1324 quests, 100% `item` tasks. No checkmark, observation, dimension, advancement, kill, stat, or location tasks. Nothing asks the player to *look at* a Loomframe, *stand in* the Clowder Hall, *strike* a Drumheart, or *arrive* in the March.
- Rewards: 1286 × one Frayed Thread. No loot tables, no XP, no cosmetics, no pages, no "Steward Cache" reward crates. The reward channel — the most direct way to make Strands *feel* different — is flat.
- Descriptions: 846 of 1324 are two words. 84 descriptions are duplicated verbatim; 30+ titles repeat across chapters ("Item Vault" ×3, "Pattern Provider" ×3, "Molecular Assembler" ×3, "Porcelain Clay" ×3), which makes the quest search useless.
- Every main chain is a strict 15–35-deep linear railroad (`chain()`), which is the exact shape the plan rejects. Flexible progression mode softens it mechanically but not visually.
- Soil's optional grid has 54 entries including "Chest Spare", "Barrel Spare", "Furnace Spare", "Crafting Table Spare", "Rabbit Hide". That's the "filler pad-decor as campaign depth" anti-pattern named in PLAN.md.
- 09_spindle ("Reweave — stitch the cut, not AE2 homework") opens with Certus Quartz → Certus Dust → Sky Stone → Fluix → Silicon → Inscriber → three presses → three processors. It *is* AE2 homework. Not one Loom-native quest precedes the AE2 line.
- No chapter images, no subtitles, no hidden/secret quests, no chapter-group icons. The book looks like the generator that made it.
- Duplicate: Soil "Catch the Rain" and Sprout "Watering Can" are both `water_bucket`.

### P1: the custom items are inert

| Item | What it does today | What the story says it is |
|---|---|---|
| Whisker Codex | Right-click prints five chat lines | "quest entry + journal pages" |
| Codex Page | Nothing (plain item, stacks to 16) | Tribe margin notes, every 3rd token |
| Braid Cord | Recipe ingredient | The proof a Clowder braided three peer paths |
| Strand Tokens | Recipe ingredient, no texture-level presence in world | Strand clears that "change how the pack behaves" |
| Spindle Loom Fragment | Plain fire-resistant item | End trophy; "reweaving the sky" |

Modonomicon *and* Patchouli are already in the mod list. The Codex has a real book engine available and isn't using it.

### P1: Voidloom is a skin over Ex Deorum

- All three thread meshes are tag-aliased to the Ex Deorum drop tables (`replaceInput` on `exdeorum:sieve`). They produce identical output to string/flint/iron mesh; the only difference is the texture. The plan's "meshes that actually change early-mid resource identity" hasn't landed.
- Loomframe is a right-click clicker: one flint/clay/yarn every 3 seconds, no sound, no particle, no hopper I/O.
- Tension Barrel makes one clay ball per 10 seconds per bucket, no GUI, no batch. The Stone chapter asks for 16 clay → 16 bucket trips → ~3 minutes of babysitting, then porcelain, then the *real* sieve. It's the first thing a Normal player does after Soil, and it's the least fun station in the pack.
- No custom sounds anywhere in the pack. No custom particles anywhere in the pack.

### P1: Frayed Thread economy has not been balanced

- Supply: ~1286 Thread over the whole campaign (plus 4–6 in kits, plus Tension milestones). Each Thread also unravels to 3 string.
- Sinks: 6–80 Thread. A Nether Star for 80 Thread (≈80 quests) is a cheap beacon; 2 diamonds for 48 is proportionally worse than 64 cobble for 10. Nothing is priced against the sieve.
- The Desk "main chain" forces buying saplings before you may buy the bucket before you may buy bone meal. A shop shouldn't have dependencies.
- Tokens stack to 16 "so braids don't brick the trophy" — which is the root of P0-1 and P0-2. If tokens are earned once and *read* rather than *consumed*, the stacking hack goes away.

### P2: hygiene

- 25 alpha zips from one day in `dist/` (ignored, but prune).
- `INTERNAL/PLAN_COMPLETE.md` certifies "MET" for "Strand clears have a visible/pack consequence beyond a checkmark" — per the above it isn't met yet. Downgrade to "scaffolded".
- `Trident`, `Wolf Armor`, `Turtle Helm` sit in Claw's optional grid; they read as vanilla-pack leftovers, not Edge-walker kit.

## Part 2 — Original effects and systems to add

Everything here is buildable with what's already in the pack (KubeJS 7, NeoForge 21.1, Modonomicon, FTB Quests tasks/rewards, the four custom mods). Ordered by how much cohesion they buy per hour of work.

### A. The Token Ceremony (replaces the token recipes)

Delete the nine `_manual` token recipes. Each Strand chapter ends in a **Knot quest**: a checkmark task, `hide_until_deps_complete`, depending on the 5–8 *hand-picked* mainline beats of that chapter (not all 35). Clicking it "tensions the Strand" and rewards the token *team-wide*, plus a command reward that fires the ceremony:

- A **Strand chime**: custom sound (`ninjacatskies:strand.soil` … nine short loom-shuttle-plus-bell stingers, each pitched to the tribe — low drum for Spark, glassy for Sigil, wooden clack for Clock). Played for every online Clowder member.
- A **thread spiral** particle burst rising from the player (end_rod / enchant particles in the strand color, 9-turn helix, 2 seconds). Cheap in KubeJS via `level.spawnParticles` in a scheduled loop.
- The Steward whisper (rewritten, see D) in the team chat, once.
- Actionbar: "Soil is tensioned. Eight Strands remain."

Tokens become `stacksTo(1)`, un-craftable, un-consumable. They are proof, not ingredients.

### B. The Tension Post (placeable Strand monument, team-scoped Tension)

A new `voidloom:tension_post` (or `clowderhall:`) block: a loom-post model with nine notches. Right-click with a token to seat it; the blockstate lights that notch in the tribe color and a thin vertical thread particle rises from it. Braid Cord and the Spindle Loom Fragment are crafted *at* the post (right-click with the ingredients while the required tokens are seated) rather than consuming tokens from inventory. This:

- kills the consume/duplicate exploit and the stack-to-16 hack,
- gives every Clowder a physical monument on their pad that visibly fills in over 40 hours,
- gives Loom Tension a home: move Tension to FTB Teams data (or a saved-data map keyed by team id) and compute it from *seated tokens*, not crafts.

Milestone passives that "change how the pack behaves" — all small, all KubeJS-able, all team-wide, all only within the Clowder's claimed chunks:

| Tension | Passive | Fantasy |
|---|---|---|
| 2 (Wake+Recover) | Loomframe cooldown 60 → 40 ticks | the pad stops fraying |
| 3 (+Root) | Crops in claimed chunks get a 10% extra random tick | Rootbinder anchors |
| 4 (+Edge) | Fall damage over the void edge cancelled once per minute (Edge-walker footing) | leave the pad safely |
| 6 (+two braid paths) | Tension Barrel batches 4 at a time | the Loom hums |
| 7 (+Bind) | Sky tint shifts (see C) | the cut begins to close |
| 9 (Reweave) | Fragment effect (see F) | reweave |

### C. Make the Cut visible — sky and fog as the antagonist

The story has no antagonist a player can see. Give the Cut a body:

- **The Fray**: a permanent thin column of dark, slow `ash`/`smoke`-style particles rising from the void at the Clowder Dock (0,0) and at each pad's origin, visible from the pad. Its density scales *down* with server-wide seated tokens. At full Reweave it becomes a lit thread (end_rod column). Implemented as a server tick spawning particles around a known position for players within 96 blocks — trivial in KubeJS, no client mod needed.
- **Sky tint by Tension** (client-side, needs a small attachment sync in `ninjacatskies`): `ViewportEvent.ComputeFogColor` / sky color blending from a slightly desaturated indigo at 0 Tension toward the pack's teal/gold at 9. Subtle — players should notice on a screenshot, not on a loading screen. This is the "world flair" the story bible promises and currently doesn't deliver.
- **Loom hum ambient**: an actual looped ambient sound (`ninjacatskies:ambient.loom_hum`) near a Tension Post, volume scaled by seated tokens. Quiet, low, wooden. It makes "the Loom hums faintly" literally true.

### D. Rewrite the three voices, then give the Codex a body

Three registers, kept strictly apart:

1. **Field Desk** — OOC how-to (starter book, signs). Already fine.
2. **Whisker Codex** — the damaged assigner. Terse, wry, practical. Quest titles and descriptions belong here.
3. **Stewards** — the nine tribes speaking from the cut. Two lines each on token seat; nine margin-note Codex Pages; each line ends on a *verb*, never on a design term.

Then use Modonomicon (already shipped) to make the Whisker Codex a real book: right-click opens it; nine tribe entries unlock as tokens are seated (Modonomicon supports advancement-gated entries; fire an advancement from the Knot quest). Codex Page items become **readable** — right-click shows the margin note in a small screen (or just Component chat with the tribe header) and the page persists as a collectible. Nine pages → a "Bound Codex" cosmetic entry. The Codex's right-click chat dump goes away.

Sample rewrites (same content, in-voice):

  Spark, proposed: "Drumhearts kept the beat under the sky. Strike one and listen before you wire anything."
- Clock, today: "Gear is a braid strand—peer to Swarm and Spark, not a ladder rung."
  Clock, proposed: "Pattern-weavers sang a factory the way you'd sing a round. One cog, then the same cog again."
- Stone quest "Sift Fallen Grit", today: "Sieve is a tool, not the title."
  Proposed: "Grit-singers named every shard by its echo. Sieve until you can hear the iron."

### E. Voidloom identity: three drop tables, one shuttle sound

- Split the mesh drop tables instead of aliasing them. Keep Ex Deorum meshes as-is; give thread meshes *additive* KubeJS `exdeorum:sieve` recipes that only fire for voidloom meshes:
  - **String mesh** → 6% `voidloom:loom_lint` (new; 4 lint → 1 Void Yarn — turns sieving into the early yarn engine the tooltip promises)
  - **Flint mesh** → 3% Frayed Thread (Recover feeds the Desk economy instead of only quests doing it)
  - **Iron mesh** → 2% `voidloom:strand_filament` (new; the Loom-native ingredient Braid Cord and the Reweave chapter's *first* quest should need)
- **Loomframe** becomes a slow passive sifter: accepts a stack of dirt/gravel via hopper or hand, sifts one every 3 s with a shuttle clack (`voidloom:loomframe.sift`) and a puff of `ninjacatskies:thread` particle, outputs to an internal slot with hopper extraction. Early automation that *looks* like a loom working — before Create exists.
- **Tension Barrel**: accept water as a fluid (bucket or Create spout later), batch up to 4 dirt, a thread-ring particle rotating on the rim while it works, gurgle on finish. Cuts the Stone-chapter babysitting from ~3 minutes to under one.

### F. Reweave finale that is a finale

Right now crafting the Fragment does nothing. Proposed: the Spindle Loom Fragment is seated in the Tension Post (ninth notch). On seat:

- Server-wide broadcast in Steward voice ("The Loom-stitchers' cut is closed by <Clowder>.").
- 8 seconds of scripted effect on that pad: the Fray column at the pad snaps to a lit thread, a ring of `end_rod` particles expands across the claimed chunks, nine chime stingers play in sequence, fireworks in the Clowder's banner colors.
- The pad's sky tint locks to full Tension.
- A **Clowder Monument** advancement + an unlock: the March foothold gate (or a cosmetic "Reweaver" title in FTB Teams).
- At the Clowder Hall, a hub plaque (server saved data) lights one thread per Clowder that has reweaved — "the Hall brightens as the server reweaves."

### G. Quest regeneration pass (what to change in `generate_quests.py`)

- Add task helpers: `checkmark`, `observation` (block in view — perfect for "Raise Loomframe" / "Find the Fray"), `dimension` (Clowder Hall, Nether, End, March), `advancement`, `kill`, `stat`. Aim for ~15% non-item tasks.
- Add reward helpers: `loot` (nine "Steward Cache" loot tables, one per tribe, with small tribe-flavored pools), `xp_levels`, `command` (for ceremonies), `item` with variety. Kill the 1-Thread default: Thread should be the *Codex's* reward for mainline beats, 2–4 per beat, and side grids should reward the thing you'd want next (bone meal, a mesh, a Codex Page).
- Description generator: mainline quests get 2–3 lines (what / why-in-voice / the next concrete verb); side grids get one line but never two words.
- Unique titles across the whole book (prefix repeats with the chapter noun: "Pattern Provider (Reweave)").
- Break the 35-deep chains into 5–8 hand-picked beats + parallel clusters. The Knot quest depends on beats only.
- Reweave chapter opens Loom-native: "Spin the Filament" (Strand Filament from iron mesh) → "Splice a Braid" (Braid Cord at the Post) → *then* the AE2 line, retitled as the Digital Loom (Certus = "Cold Weft", Fluix = "Charged Warp", Inscriber = "Press the Pattern").
- Move the unobtainables (P0-3) to optional or give them pack recipes.
- `hide_until_deps_complete` on side grids until the chapter's second beat, so Soil doesn't open as a wall of 70 circles.
- Chapter images: nine tribe glyphs (small, 32px, in the same palette as the token textures) as chapter icons and background images.

### H. Small polish that adds up

- Steward whisper colors: use the pack's teal `#3D7A7A` for line one and gold `#D4A84B` for line two; drop the indigo — it's a background color, not a text color.
- Shop chapter: remove dependencies between purchases; reprice against sieve time (a rough rule: 1 Thread ≈ 90 seconds of Recover). Nether Star → 200+; diamonds 48 → 30.
- Dedupe "Watering Can"; replace with an actual watering tool if Botany Pots/Farmer's Delight expose one.
- Retire "Chest Spare / Barrel Spare / Furnace Spare / Crafting Table Spare" and the Claw vanilla leftovers; fold pad-comfort items into one "Pad Comforts" checklist quest with a loot reward.
- Add an "unreachable in void" denylist to `tools/audit_quest_items.py` so P0-3 can't regress.
- Splash lines and FancyMenu tagline are in voice — keep them; add a Fray still to the title sky (the column, faint) so the antagonist is on the first screen.
- First commit.

## Part 3 — Suggested order

1. **Commit.** (10 minutes.)
2. **Token Ceremony + Tension Post + team-scoped Tension** (A, B). This is the change that makes the Strand system real; everything else hangs off it.
3. **Voice pass** on steward lines, Codex right-click, and the ~40 leaking quest descriptions (D, first half). One afternoon; highest cohesion per hour.
4. **Voidloom drop tables + Loomframe passive sift + Barrel batch** (E). Fixes the first 30 minutes of Recover, which is where players decide whether the pack is "authored".
5. **Quest regeneration** with task/reward variety, unique titles, beats instead of chains, Reweave opening Loom-native, unobtainables fixed (G).
6. **The Fray + sky tint + hum ambient** (C), then **Reweave finale** (F), then the Codex as a Modonomicon book (D, second half).

Items 2–4 are mostly KubeJS plus modest Java in `voidloom`/`ninjacatskies`; item 6's sky tint is the only piece that needs a client-side attachment sync.
